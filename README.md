# 딸깍 인생 · B트랙 도메인 스토리텔링

허들링 클럽 1차 실험 **트랙 B** 제출용 공개 문서 저장소입니다. 기존 비공개 게임 저장소와 분리했습니다.

## 제출 파일

- [`story-service.md`](story-service.md) — 플레이어가 하는 일(RO-A), 유저 스토리 5문장, 어기면 안 되는 조건 2개
- [`story-work.md`](story-work.md) — 제작자가 하는 일(RO-B), 작업 7문장과 산출물·멈칫·넘김 후보

## 함께 읽을 문서

- [`PRD.md`](PRD.md) — 비공개 제품 자료를 바탕으로 한 공개용 5블록 요약
- [`CLAUDE.md`](CLAUDE.md) — 이 제출 문서를 수정할 때 지킬 기준

## 상태

`story-service.md`는 2026-09-30 기준 제품 기록에서 추출한 초안입니다. `story-work.md`는 **제작자의 실제 수작업 순서 확인 전** 자료 기반 재구성입니다. 이 저장소를 과제에 제출할 때는 작업 스토리의 7문장, 멈칫한 순간, 실제 산출물 이름을 제작자가 확인해야 합니다.

## 자료 범위

- 과제 방식: 제공된 PDF 2종 중 서비스/작업 도메인 구분과 B트랙 제출 기준
- 제품 사실: 별도 비공개 `clack-life` 저장소의 PRD, 변경 기록, 이야기 지도·스토리 UI 문서

강의 PDF, 비공개 제품 자료, 외부 레퍼런스 이미지와 앱 소스는 이 저장소에 포함하지 않았습니다.
